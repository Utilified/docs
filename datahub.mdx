The Reference library holds the shared reference data the rest of UMS depends on. Tariffs, validation, and reports all read from these records, so they stay consistent across every organisation.

Open it from the utility menu by selecting **Reference library** (`/reference-library`). The menu entry is hidden for users whose role denies access to resources.

<Note>
  Reference library records are shared platform data. You can browse and view them; only Utilified staff can create or edit them. If a date group, time-of-use schedule, or quantity looks wrong, contact Utilified support.
</Note>

## Browsing reference data

The page groups data types into four sections. A **Search data types...** field in the top-right filters the cards by title, description, or section.

| Section                      | Data types                                                         |
| ---------------------------- | ------------------------------------------------------------------ |
| **Temporal data**            | **Dates**, **Manual Dates**, **Time of Use**                       |
| **Technical specifications** | **Quantities**, **Factors**, **Base Units**, **Scientific Units**  |
| **Geographic reference**     | **Countries**, **States & Regions**                                |
| **Infrastructure**           | **Markets**, **Utilities**, **Namespaces**                         |

Select a card to open its records in a dialog. Open any record from the grid to see its detail page. Click **Close** to return to the cards.

## Dates

**Dates** are system-generated date groups and calendars, such as public-holiday sets. Time-of-use labels reference date groups to decide which days a time window applies to. **Manual Dates** hold custom date entries and special occasions.

## Time of Use

A time-of-use (TOU) record defines the time-based periods, such as peak, off-peak, and shoulder, that tariffs price differently. Accurate TOU definitions are essential for correct invoice validation.

A TOU's page shows:

- **Details** — the **ID**, **Name**, **Timezone**, and **Default label**
- **Labels** — a table with **Label**, **Time windows**, and **Date groups** columns. The default label is marked **Default** and covers everything else. A label with no date groups applies **Every day**.
- **Weekly preview** — a grid showing which label applies at each time across the week

<Tip>
  **TOU** stands for Time of Use. See [Key concepts](/getting-started/key-concepts) for related terminology.
</Tip>

## Quantities, factors, and units

- **Quantities** — billed quantities and how read quantities are calculated
- **Factors** — calculation factors and multipliers applied during energy and cost calculations
- **Base Units** — fundamental measurement units, such as kWh
- **Scientific Units** — advanced scientific measurement units

## Geographic and infrastructure reference

**Countries**, **States & Regions**, **Markets**, **Utilities**, and **Namespaces** hold the supporting reference records that sites, connections, and tariffs link to. They follow the same list-and-detail pattern.
