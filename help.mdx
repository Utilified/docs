Use **Contact Utilified** to send a question, report a problem or ask for a feature without leaving UMS. Utilified replies inside the request, and you get a notification when they do.

<Note>
  Contact Utilified only appears when it is enabled for your organisation. Without it, **Support** in the sidebar opens the external support form instead.
</Note>

## Send a request

<Steps>
  <Step title="Open Contact Utilified">
    Select **Support** in the sidebar. You can also open **Help requests** in the sidebar and click **Contact Utilified**.
  </Step>
  <Step title="Choose what it is about">
    Pick one of:

    - **Question**: "How do I…?"
    - **Data problem**: a number or record looks wrong
    - **Bug**: something is broken
    - **Feature request**: something you need
  </Step>
  <Step title="Describe it">
    Enter a **Subject** and **Description** (both required).

    For a **Bug**, you can also fill in **Steps to reproduce**, **Expected** and **Actual**. For a **Feature request**, you can add **What are you trying to do?**
  </Step>
  <Step title="Send">
    Click **Send**. The request appears in **Help requests**.
  </Step>
</Steps>

<Tip>
  The page you were on is sent with your request. Open **Support** from the page the problem is on, so Utilified can see it in context.
</Tip>

## Follow your requests

**Help requests** lists the requests you have sent, with the latest activity first. Each row shows the subject, the request type, the date of the last message and its status.

| Status | Meaning |
| --- | --- |
| **Open** | Utilified has the request. |
| **Waiting on you** | Utilified needs a reply from you. |
| **Planned** | The fix or feature is planned. |
| **Shipped** | The fix or feature has been released. |
| **Resolved** | The request is closed. |
| **Won't do** | Utilified won't action the request. |

## Reply to a request

Click a request to open it. The page shows the details you sent and the conversation with Utilified, which refreshes as new messages arrive.

To reply, type in the **Reply** box and click **Send**. You can also press `Ctrl+Enter` (`Cmd+Enter` on Mac).
