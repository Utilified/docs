Data feeds bring external data into UMS for an account. They are organised in three levels:

- **Data feed** — a named feed for one account and one data type
- **Data source** — where the feed's data comes from. A feed can have several sources.
- **Data source file** — a file a source delivered, and how its processing went

Processed files create [site data](/site-data) records, and each record links back to the file it came from.

## Data feeds

Go to **Portfolio** › **Connections** › **Data feeds**. The grid lists every data feed in your organisation.

- Click **New Data Feed** to create a feed
- Click **Data sources** to see every data source across all feeds

A feed's page shows the account as its subtitle and has three tabs:

- **Overview** — **Feed information** (**Name**, **Description**, **Data type**, **Created** and **Last modified**), plus a link to the feed's data sources
- **Data sources** — the sources attached to this feed
- **Settings** — the feed's details and a **Danger zone** with **Delete data feed**

Click **Add data source** to attach a new source, or **Edit** to change the feed.

## Data sources

The **Data sources** page (`/data-sources`) lists every data source across all feeds.

- Click **New Data Source** to create a source
- Click **Files** to see every file delivered by any source

A source's page shows its data feed and account as the subtitle, and has three tabs:

- **Overview** — **Source information** (**Name**, **Description**, **Created** and **Last modified**)
- **Files** — the files this source has delivered. Click **Upload File** to add one to this source
- **Settings** — the source's details and a **Danger zone** with **Delete data source**

Click **Edit** to change the source.

## Data source files

The **Data source files** page (`/data-source-files`) lists every file delivered by any data source. Click **Upload File** to add a file manually.

A file's page shows the data source it came from as its subtitle, and its processing status in the header. Below are:

- **File information** — **File name**, **Records created**, **Date created** and **Date processed**
- **Processing errors** — any errors reported while the file was processed
- **Processing summary** — the summary recorded when processing finished

Click **Edit** to change the file's details.

The processing status is one of **Pending**, **Processing**, **Completed** or **Failed**.

<Tip>
  If a file shows **Failed**, read the **Processing errors** panel to see what went wrong, fix the file, and upload it again.
</Tip>
