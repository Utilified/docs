Meters, registers and reads sit beneath a [connection](/connections) and describe how energy use is measured and recorded. A connection can have many meters. Each meter has one or more registers (measurement channels), and each register records a stream of time-series reads.

```text
Connection (utility meter point — NMI, MIRN)
└── Meter (physical device)
    └── Register (measurement channel)
        └── Reads (time-series consumption data)
```

Find meters under **Portfolio** › **Connections** › **Meters**, or on a connection's **Metering** › **Meters** segment. Registers have no list of their own: open one from its meter. You need access to the Utilities module.

## Meters

The **Meters** tab lists every meter across your connections. Click **New Meter** to add one, or use **New Meter** on a connection's page to add it to that connection directly.

| Column            | Description                                                                 |
| ----------------- | --------------------------------------------------------------------------- |
| **Serial**        | The meter's serial number. Click it to open the meter                       |
| **Type**          | The meter type                                                              |
| **Installed**     | When the meter was installed. Marked "from meter data" when UMS filled it in from the reads |
| **Removed**       | When the meter was removed (blank if still installed)                       |
| **Data provider** | Where the meter's data comes from                                           |
| **First read**    | The date of the earliest read                                               |
| **Last read**     | The date of the latest read                                                 |

### Meter page

The header shows the serial number, an **Active** or **Inactive** status and a link to the connection it's on. Click **New Register** to add a register to the meter.

| Tab           | What it shows                                                                          |
| ------------- | -------------------------------------------------------------------------------------- |
| **Overview**  | **Meter details** (serial number, type, description, install and removal dates) and **Record** (**Date added** and **Last edited**) |
| **Registers** | The meter's registers                                                                  |
| **Reads**     | Every read from all of the meter's registers                                           |
| **Settings**  | Edit the meter's details, or archive or delete it                                      |

## Registers

A register is a measurement channel on a meter, for example separate channels for peak and off-peak use, or for import and export. A meter's **Registers** tab lists them.

| Column           | Description                                                     |
| ---------------- | --------------------------------------------------------------- |
| **Serial**       | The register's serial number                                    |
| **Interval (s)** | The read interval length in seconds                             |
| **Accumulator**  | How readings accumulate: cumulative or actual                   |
| **Flow**         | Injection, extraction or net                                    |
| **Units**        | The unit of measure for the register's reads                    |
| **Status**       | Active or Inactive                                              |

### Register page

The header shows the serial number, an **Active** or **Inactive** status and a link to the meter it's on. Click **New Read** to add a read by hand.

| Tab          | What it shows                                                                                                   |
| ------------ | --------------------------------------------------------------------------------------------------------------- |
| **Overview** | **Register details** (serial number, base units, interval, accumulator type, flow direction) and **Record** (**Date added** and **Last edited**) |
| **Reads**    | The register's reads                                                                                            |
| **Settings** | Edit the register's details, or archive or delete it                                                            |

## Reads

Reads are the time-series measurements a register records. They underpin validation, modelling and brokerage. A register's **Reads** tab lists them one by one; a meter's **Reads** tab lists them across all its registers.

| Column       | Description                                   |
| ------------ | --------------------------------------------- |
| **Date**     | The date of the read                          |
| **Interval** | The interval within the day the read covers   |
| **Value**    | The recorded measurement                      |
| **Recorded** | When the read was recorded                    |

The grid also shows whether each read is an actual reading or an estimate. Reads are sorted by **Date**, then **Interval**, most recent first.

To chart and export a connection's reads across all its meters, use the connection's **Metering** › **Reads** segment. See [Connections](/connections#metering).
